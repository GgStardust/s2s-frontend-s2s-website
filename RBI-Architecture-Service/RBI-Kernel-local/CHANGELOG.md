# Changelog

All notable changes to the RBI Kernel project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-11-09

### Added
- Initial release of RBI Kernel
- REST API endpoints for resonance scoring and vector similarity
- S2S API endpoints (`/rbi/*`)
- Core computation functions (resonance scoring, vector similarity, neighbor finding)
- Docker support
- Comprehensive documentation:
  - API Reference
  - Architecture documentation
  - Plugin mode usage guide
- TypeScript implementation with Fastify framework
- Health check endpoint
- OpenAPI specification
