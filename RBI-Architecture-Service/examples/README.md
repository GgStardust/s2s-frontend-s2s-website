## Overview

This directory contains practical examples of RBI (Resonance-Based Intelligence) integration across different projects and use cases. Each example includes:

- **Value Assessment**: ROI analysis, operational benefits, and impact metrics
- **Implementation Guide**: Step-by-step integration instructions with exact API formats
- **Code Examples**: Minimal integration snippets you can adapt to your project

## Adding Your Own Example

If you've integrated RBI into your project and want to share it:

1. Create a new directory: `examples/your-project-name/`
2. Include:
   - `README.md` - Project overview and links
   - `VALUE_ASSESSMENT.md` - ROI and benefits analysis
   - `IMPLEMENTATION_GUIDE.md` - Integration instructions
   - `integration-snippet.ts` - Minimal code example
3. Submit a pull request or contact the RBI team
