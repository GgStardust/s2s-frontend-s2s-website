# How to Share Your RBI Demo

## Quick Share Options

### Option 1: GitHub Pages (RECOMMENDED - Best for Sharing)

**This is the easiest and most reliable way to share your demo!**

1. **Go to GitHub Pages Settings:**
   - Visit: https://github.com/GgStardust/S2S-RBI-System/settings/pages

2. **Configure:**
   - Under "Source", select:
     - **Branch:** `main`
     - **Folder:** `/RBI-Architecture-Service/public`
   - Click **"Save"**

3. **Wait 1-2 minutes** for GitHub to build your site

4. **Your shareable URL will be:**
   ```
   https://ggstardust.github.io/S2S-RBI-System/tpb-comprehensive-demo.html
   ```

5. **Share that URL!** Anyone can open it in their browser.

**Why this is best:** Works reliably, professional URL, no downloads needed.

---

### Option 2: Download & Share File
1. Go to: https://github.com/GgStardust/S2S-RBI-System/tree/main/RBI-Architecture-Service/public
2. Click on `tpb-comprehensive-demo.html`
3. Click the "Raw" button (top right)
4. Right-click and "Save As" to download
5. Share the file via email, Dropbox, Google Drive, etc.
6. Recipients open it in their browser (double-click the file)

---

### Option 3: GitHub Pages (Best for Professional Sharing)

This creates a public website URL that anyone can access.

#### Step-by-Step Setup:

1. **Go to your GitHub repository:**
   - Visit: https://github.com/GgStardust/S2S-RBI-System

2. **Open Settings:**
   - Click "Settings" tab (top right of repository)

3. **Go to Pages:**
   - Click "Pages" in the left sidebar

4. **Configure Pages:**
   - **Source:** Select "Deploy from a branch"
   - **Branch:** Select `main`
   - **Folder:** Select `/RBI-Architecture-Service/public`
   - Click "Save"

5. **Wait 1-2 minutes** for GitHub to build your site

6. **Get your shareable URL:**
   - GitHub will show: `https://ggstardust.github.io/S2S-RBI-System/`
   - Your demo will be at: `https://ggstardust.github.io/S2S-RBI-System/tpb-comprehensive-demo.html`

7. **Share the link!** Anyone can open it in their browser.

---

### Option 4: Vercel Deployment (Most Professional)

If you want a custom domain and better hosting:

1. Go to: https://vercel.com
2. Sign up/login with GitHub
3. Click "Add New Project"
4. Import your repository: `GgStardust/S2S-RBI-System`
5. Configure:
   - **Root Directory:** `RBI-Architecture-Service`
   - **Build Command:** (leave empty or `npm install`)
   - **Output Directory:** `public`
6. Click "Deploy"
7. Vercel gives you a URL like: `https://s2s-rbi-system.vercel.app`
8. Share that URL!

---

## Which Option Should You Use?

- **Quick test:** Option 1 (GitHub raw link)
- **Sharing with a few people:** Option 2 (download & share file)
- **Professional sharing:** Option 3 (GitHub Pages) - **RECOMMENDED**
- **Production deployment:** Option 4 (Vercel)

## Troubleshooting

**If the demo doesn't load:**
- Make sure you're using the full URL (not just the file path)
- Try opening in a different browser
- Check that GitHub Pages is enabled in repository settings

**If you see code instead of the demo:**
- Use Option 2 (download the file) or Option 3 (GitHub Pages)
- Make sure the file has `.html` extension

**Need help?** The demo works standalone - no server needed. Just open the HTML file in any modern browser.
