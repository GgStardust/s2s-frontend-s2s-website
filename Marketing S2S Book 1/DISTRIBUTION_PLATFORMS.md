### 2. Bookshop.org

**URL:** https://bookshop.org  
**Target Audience:** Independent bookstore customers, conscious consumers

**Setup Requirements:**
- ISBN
- Book metadata
- Cover image
- Book description
- Author bio

**Fees:**
- ~30% commission
- Payment processing included

**Pros:**
- Supports independent bookstores
- Good for discovery
- Ethical positioning aligns with S2S values
- No upfront costs

**Cons:**
- Lower profit margin
- Less control over presentation

**Action Items:**
- Research independent bookstore partnerships
- Prepare metadata aligned with canonical wrapper
- Create bookstore-friendly description

**Timeline:** Set up 2-3 months before launch

### 4. Gumroad

**URL:** https://gumroad.com  
**Target Audience:** Direct buyers, digital-first readers

**Setup Requirements:**
- Gumroad account
- Product listing
- Digital file (PDF/EPUB)
- Optional: Print-on-demand integration

**Fees:**
- ~10% commission (very low)
- Payment processing included

**Pros:**
- Lowest fees of major platforms
- Direct customer relationship
- Good for bundles (print + digital)
- Simple setup
- Good analytics

**Cons:**
- Less discovery than major retailers
- Requires own marketing

**Action Items:**
- Create Gumroad account
- Set up product listing
- Create bundle options (print + digital)
- Link from website

**Timeline:** Set up 1-2 months before launch

---

### 5. Amazon (Consideration)

**URL:** https://kdp.amazon.com  
**Target Audience:** Maximum reach, mainstream discovery

**Setup Requirements:**
- Amazon KDP account
- ISBN
- Print-ready PDF
- EPUB file
- Cover image
- Metadata

**Fees:**
- 30-60% commission (varies by format)
- Print-on-demand: cost per book + commission

**Pros:**
- Largest reach
- Built-in discovery
- Print-on-demand included
- Good for SEO

**Cons:**
- Lower profit margins
- Less control
- Amazon's policies
- May conflict with "independent" positioning

**Decision Factors:**
- **Pro:** Maximum reach, many readers expect Amazon
- **Con:** May dilute "independent" positioning
- **Recommendation:** Consider after initial launch, or use selectively

**Action Items (if proceeding):**
- Research Amazon KDP requirements
- Prepare files to Amazon specifications
- Consider Amazon-exclusive vs. wide distribution

**Timeline:** If proceeding, set up 2-3 months before launch

---

### 6. IngramSpark (Wholesale Distribution)

**URL:** https://www.ingramspark.com  
**Target Audience:** Bookstores, libraries, institutions

**Setup Requirements:**
- IngramSpark account
- ISBN
- Print-ready files
- EPUB file
- Cover image
- Metadata

**Fees:**
- Setup fee: ~$49 (one-time, or free with promo codes)
- Per-book printing costs
- Wholesale discount: ~55% to retailers

**Pros:**
- Gets book into physical bookstores
- Library distribution
- Institutional sales
- Professional distribution network

**Cons:**
- Lower profit margins (wholesale discount)
- Setup complexity
- Upfront costs
- Less control over pricing

**Action Items:**
- Research bookstore interest
- Calculate profitability with wholesale discount
- Consider if physical bookstore presence is priority

**Timeline:** If proceeding, set up 3-4 months before launch

## Pricing Strategy

### Recommended Pricing:

- Direct (website): $44 USD

- Wholesale (IngramSpark): Set to allow ~55% discount to retailers

**Digital Edition:**
- Direct (website): $22 USD
- Retail platforms: $22 USD (maintain consistency)

**Bundle:**
- Direct (website): $55 USD
- Gumroad: $55 USD

**Rationale:**
- Maintain price consistency across platforms
- Direct sales remain most profitable
- Retail platforms provide discovery, not primary revenue
