## Content Extraction Workflow

### Step 1: Open All Source Files
Create bookmarks/favorites for:
1. Gateway corpus (Tier 0/Tier 1a expansion)
2. Scrollstreams export
3. Core Inquiry document
4. UNIFIED_SOCIAL_STRATEGY.md
5. Website content (if needed)

### Step 2: Create Extraction Spreadsheets

**Gateway_Statements.xlsx:**
- Column A: Invariant #
- Column B: Pattern (P1-P10)
- Column C: Line 1
- Column D: Line 2
- Column E: Line 3
- Column F: Line 4 (Question)
- Column G: Status (Ready/Needs Edit)
- Column H: Date Used

**Scrollstreams_Selected.xlsx:**
- Column A: Content
- Column B: Orb #
- Column C: Source Location
- Column D: Status
- Column E: Date Used

**System_Definitions.xlsx:**
- Column A: Definition Text
- Column B: Source
- Column C: Status
- Column D: Date Used

### Step 3: Batch Extraction Session

**Session 1: Gateway Statements (2 hours)**
- Extract 30-40 ready-to-use statements
- Organize by Invariant/Pattern
- Mark status in spreadsheet

**Session 2: Scrollstreams (1 hour)**
- Review scrollstreams export
- Select 20-25 fragments
- Copy to spreadsheet

**Session 3: Supporting Content (1 hour)**
- Extract 5-7 System Definitions
- Extract 3-5 Core Inquiry questions
- Extract 5-7 Book Excerpts

### Step 4: Content Calendar Population

**Fill 7-week calendar:**
- Assign Gateway Statements to Mondays
- Assign Scrollstreams to Wednesdays
- Rotate System Definitions, Inquiries, Book Excerpts on Fridays
- Ensure variety across Invariants and Patterns

## Content Quality Checklist

Before using any content, verify:

- [ ] Aligns with S2S principles (structural, not spiritual)
- [ ] No transformation promises
- [ ] No instruction or advice
- [ ] Declarative tone
- [ ] Standalone (no context needed)
- [ ] Appropriate length for format
- [ ] No em dashes
- [ ] No negative framing
- [ ] Affirmative definitions only

## Tips for Efficient Extraction

1. **Use Find/Replace:** Search for specific patterns in files
2. **Copy to Spreadsheet First:** Don't create posts until content is organized
3. **Batch Similar Content:** Extract all Gateway Statements in one session
4. **Mark What's Used:** Track in spreadsheet to avoid repetition
5. **Save Favorites:** Bookmark best content for easy access
