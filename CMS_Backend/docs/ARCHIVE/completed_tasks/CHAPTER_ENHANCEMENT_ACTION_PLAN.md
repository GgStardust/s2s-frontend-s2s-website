   - **Usage:** All enhancements sourced from codex library using R_ij scoring — preserves original text, no condensing
6. **Targeted, Not Exhaustive:** Use source material strategically, not comprehensively.
7. **Flexible Expansion:** Chapters with rich source material (50,000+ words) can expand more substantially (even into 2 sections or longer) to utilize research effectively. Chapters with low content will be enhanced after generating more content.
8. **"In Plain Terms" Summaries (Narrative Paragraph Style):**

   - **Style:** Match each chapter's Orb persona (e.g., Orb 1 = whispered, primordial, poetic; Orb 4 = structural, geometric, architectonic)
   - **Integration:** Flow seamlessly from scientific explanation → plain-language summary (NO labels like "Recognize this:" or "In plain terms:")

   - **Purpose:** Bridge technical explanations to chapter's core themes, making complex concepts accessible while maintaining transmission tone
