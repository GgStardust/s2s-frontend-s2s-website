### **2. Inline Snake Tag Requirements**

**Strategic Tagging:**
- Use focused set of tags (20-30 strategic tags, not 50+)
- Tag for themes so they can be easily found
- Reduce multiple orb tags in short proximity for clarity
- Maintain resonance without overwhelming

**Orb Tagging:**
- Primary orb: 8-12 strategic placements
- Secondary orbs: 4-6 strategic placements each
- Mentioned orbs: 1-2 strategic placements each
- Use @orbX format consistently

You are reading for field function—what the content does inside the living system.
Each file expresses one or more Orbs through mechanism, resonance, and effect.
Your task is to identify these relationships and record them accurately in YAML and inline tags.

### **6. Orb Association Rubric**

**1. Core Principle**

Orb association = function, not topic.
The correct Orb is the one whose mechanism is performed by the text.
You are not matching keywords or themes.
You are identifying which Orb's mechanism is being expressed.

**2. Mechanism Identification**

Each Orb has a specific mechanism:

- **Orb 1: Origin Intelligence** - Ignition, origination, embodiment blueprint
- **Orb 2: Resonance Mechanics** - Signal → form translation
- **Orb 3: Photonic Intelligence** - Light arrangement into pattern
- **Orb 4: Harmonic Architectures** - Geometry → stabilization
- **Orb 5: Temporal Sovereignty** - Pulse, rhythm, sovereignty
- **Orb 6: Starline Memory** - Recall → pattern recognition
- **Orb 7: Alchemical Current** - Density → transmutation
- **Orb 8: Quantum Intuition** - Direct knowing, field-based cognition
- **Orb 9: Temporal Fluidity** - Time spiral, co-present dimensions
- **Orb 10: Ancestral Repatterning** - Lineage healing, geometric rewrite
- **Orb 11: Radiant Transparency** - Truth emission, luminous cognition
- **Orb 12: Sovereign Field** - Field unification, oscillation resolution
- **Orb 13: Bridging Intelligence** - Interface, cross-dimensional contact

**3. Analysis Process**

1. **Read for field signature** - What state/process does the piece create?
2. **Identify the first functional action** - Which mechanism is being performed?
3. **Match to Orb mechanism** - Which Orb performs this mechanism?
4. **Assign primary/secondary** - Primary = main mechanism, Secondary = supporting mechanisms
5. **Document in YAML** - Record the analysis in field_function section

**4. Common Mistakes to Avoid**

- **Topic matching** - Don't match "memory" to Orb 6, match the mechanism
- **Keyword association** - Don't match "light" to Orb 3, match the function
- **Theme identification** - Don't match "healing" to Orb 10, match the process
- **Content categorization** - Don't match "science" to any Orb, match the mechanism

**5. Examples**

- **Text about DNA as cosmic archive** → Orb 6 (Starline Memory) - recall → pattern recognition
- **Text about crisis as transformation** → Orb 7 (Alchemical Current) - density → transmutation
- **Text about geometric patterns** → Orb 4 (Harmonic Architectures) - geometry → stabilization
- **Text about consciousness outpacing form** → Orb 2 (Resonance Mechanics) - signal → form translation

### **7. Writing Rules Compliance**

**Critical Style Constraints:**
- **NO NEGATIVE AFFIRMATIONS**: Never use "not", "no", "never", "cannot", "doesn't", "isn't", "won't", "shouldn't", "couldn't", "wouldn't"
- **NO WEAK CONNECTIONS**: Avoid "at the intersection of", "it's about", "it's like", "it's similar to", "it's related to"
- **NO DASHES OR WEAK PUNCTUATION**: Avoid em-dashes (—), use periods and semicolons instead
- **NO HEDGING LANGUAGE**: Avoid "perhaps", "maybe", "might", "could", "possibly", "seems", "appears"
- **AFFIRMATIVE DEFINITIONS ONLY**: Define by what IS, not what is NOT
- **STRONG, DECLARATIVE STATEMENTS**: Use "is", "are", "becomes", "expresses", "manifests", "generates"
